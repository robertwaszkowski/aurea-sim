# AureaSim projects workspace

This directory is the runtime workspace displayed by the web interface.

The release includes three curated, completed projects:

- `Incident Management`;
- `Leave Request`;
- `RES_Sales_Process`.

They provide ready-to-open BPMN models, parameters, scenario definitions,
completed logs, KPI tables, charts, and reports. All included scenario logs
completed successfully and passed the v1.2.0 gallery audit.

New simulations create additional project directories here. Generated
projects, imported candidate packages, review ledgers, and hybrid exports are
local application state and are ignored by Git unless deliberately curated in
a future release.
